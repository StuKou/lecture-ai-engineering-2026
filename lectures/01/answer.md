        2. **必要なマシンパワーが低い:** 一般的なゲーミングPC程度のグラフィックボード（GPU）でも学習が可能になった。

    ---

    ---


    通常は、作業用のブランチを新しく作成しながらそのタグに切り替えます。
    ```bash
    git checkout -b work-lec01 lec01-start
    ```
    *※ブランチ名（`work-lec01` の部分）は講義の指示や自分の好みに合わせます。*
